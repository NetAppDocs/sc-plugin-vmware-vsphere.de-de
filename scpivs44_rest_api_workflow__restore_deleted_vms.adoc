= REST-API-Workflow zur Wiederherstellung gelöschter VMs mithilfe des SCV
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Um die Restore-Vorgänge für VM-Backups mit dem SnapCenter Plug-in für VMware vSphere REST-APIs durchzuführen, müssen Sie die vorgeschriebene Sequenz von REST-API-Aufrufen befolgen.

Fügen Sie für jede REST-API hinzu `\https://<server>:<port>` An der Vorderseite der REST-API zu einem vollständigen Endpunkt

|===
| Schritt | REST API | Kommentare 


| 1 | Gehen Sie zu `\http://<vCenter-IP>/mob` | Den Datastore-*moref* aus der VMware Managed Objects URL ermitteln. Den moref für den Datastore notieren, auf dem die gelöschte VM gespeichert war. 


| 2 | `/4.1/datastores/{moref}/backups` | `Get Datastore Backups` ruft eine Liste der Backups für den angegebenen Datenspeicher ab. Den *moref* aus Schritt 1 übergeben. Die *backupId* des Backups, das wiederhergestellt werden soll, notieren. 


| 3 | `/4.1/backups/{backupId}` | `Get Backup Details`Ruft die Details des angegebenen Backups ab. Die *backupId* aus Schritt 2 übergeben. In der Entitätenliste ist die *entityName* zu finden, die der gelöschten VM entspricht, und die *UUID* ist zu notieren. 


| 4 | `/4.1/vm/backups/{backupId}/snapshotlocations` | `Get snapshot locations` Ruft den Speicherort des Snapshots für die angegebene Sicherung ab. Die *backupId* aus Schritt 2 übergeben. Die Informationen zu *snapshotLocationsList* sind zu beachten. 


| 5 | `/4.1/datastores/{moref}/availableEsxHosts` | `Get available ESX Hosts` Ruft die Informationen für den Host ab, auf dem der Backup gespeichert ist. Den *moref* aus Schritt 1 übergeben. Die Informationen zu *availableEsxHostsList* beachten. 


| 6 | `/4.1/vm/{uuid}/backups/{backupId}/restoreVm` | `Restore a VM from a backup`Stellt das angegebene Backup wieder her. Die *UUID* aus Schritt 3 übergeben. Die *backupId* aus Schritt 2 übergeben. Im *restoreLocations*-Attribut die Informationen aus *snapshotLocationsList* aus Schritt 4 übergeben; im *esxHost*-Attribut die Informationen aus *availableEsxHostsList* aus Schritt 5 übergeben. Wenn das VM-Backup ein partieller Backup ist, den  `restartVM` Parameter auf *false* setzen. *Hinweis:* Es kann keine VM wiederhergestellt werden, die eine Vorlage ist. 
|===
